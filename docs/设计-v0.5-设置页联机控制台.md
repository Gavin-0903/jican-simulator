# 设计：v0.5 设置页 = 联机控制台

> 目标（用户原话）："加入设置页面，里面能看到ID密钥，本机联机服务器是否启动，然后还有本联机服务器token等信息，还能修改是用哪种TailScale协议（Funnel, Stave, TailNet等）"

## 1. 界面结构

设置弹窗（`client/js/ui/SettingsPanel.js`）拆成三个标签，默认停在「联机」：

- **联机**（联机控制台，本文件重点）
- **画面**（镜头跟随/全景、老师视野扇形显示、网络延迟、随机种子）
- **操作**（快捷键 / 道具快捷键 / 输入控制说明）

切换标签只调 `modals.setBody('settings', buildBody())`，整窗不重建 —— 避免焦点与输入状态丢失。设置弹窗加宽靠 `modals.current.card.classList.add('settings-wide')`（`ModalHost.open` 不支持自定义类名）。

「联机」标签从上到下五块：

1. **配置漂移警示条**（有漂移才出现，黄色）
2. **ID 密钥**
3. **本机联机服务器**
4. **联机 Token**
5. **TailScale**

### 1.1 ID 密钥

- 掩码 `5361d110…` 来自 `GET /api/net/admin` 的 `idKey.hint`。
- 「显示完整」点击后向 `GET /api/net/info` 取一次 256 位完整密钥，缓存在 `this.idKeyFull`（**不进 console、不进 URL**）。
- 「复制」走按钮 + `navigator.clipboard`（游戏内 Ctrl+C 已被 `client/js/util/ime.js` 全拦，只能用按钮）。
- 展开后额外公示来源路径（`idKey.file`）与长度（256 字符 = 256 位十六进制）。

### 1.2 本机联机服务器

判据是**服务端实测事实**，不是配置里的意图值：

```
已启动 ⇔ online.enabled === true && tailscale.serveStatus.ok && tailscale.serveStatus.port === 当前监听端口
```

展示：本页地址 / 监听地址 / 对外地址（`https://<节点>.<tailnet>.ts.net`）/ 数据目录 / 房间数（可展开房间表）/ 监听端口（5173 默认 ↔ 当前端口 可切）。
操作：「开启联机」（`POST /api/net/online/mode {mode:'tailnet'}`）、「重启服务器」（`POST /api/net/admin/restart`）。

### 1.3 联机 Token

- 有 Token：掩码 + 「显示完整」（**二次确认**弹窗，因为 Token 等于房间口令）+「重新生成」+「复制」。
- 无 Token：也给「生成」按钮（否则这一块永远是死信息），点了就是 `POST /api/net/token/regenerate`。
- 完整 Token 走 `GET /api/net/admin/token`；404/501 时置 `hasTokenApi=false`，提示「当前服务端版本不支持查看完整 Token」，不报错。
- 重新生成后旧 Token 立即失效，服务端会 `rooms.clear()`（已建房间都绑旧 Token，必须重新加入）。

### 1.4 TailScale 三选一

```
Serve（tailnet 内） | Funnel（公网） | 关闭
```

对外契约一律 `'tailnet' | 'funnel' | 'off'`：入参 `'serve'`→`'tailnet'`、`'disabled'`→`'off'`，大小写不敏感；老配置里的 `'serve'` 在 GET 时归一化成 `'tailnet'`。
`funnelCapable === false` 时 Funnel 按钮禁用并列出原因（缺 https 证书 / 未登录 tailnet / 端口不在允许列表）。切换中所有模式按钮 disabled 并显示「切换中…」，失败把服务端 `error` 原样显示。

**Funnel 端口常识（必须写进 UI 文案）**：TailScale Funnel 只允许 443 / 8443 / 10000。本机服务在 5173，对外靠 `tailscale serve` 把 `https://<节点>.ts.net:443` 反代到 `http://127.0.0.1:5173`，所以对外的 443 入口不随本机端口变化。

## 2. 服务端接口

| 接口 | 方法 | 限定 | 返回 |
| --- | --- | --- | --- |
| `/api/net/admin` | GET | 回环 | 脱敏的完整快照：`app/dataDir/port/idKey{hint,length,file}/online{enabled,mode,serverUrl,port,hasToken,tokenMasked,tokenLength}/tailscale{...}/rooms{count,list}/settings/isServerSource/drift{state,mode,configMode,actualMode,drift[]...}` |
| `/api/net/admin/token` | GET | 回环 | `{ok, token, length, hasToken, masked}`（**唯一返回完整 Token 的接口**） |
| `/api/net/token/regenerate` | POST | 回环 | `{ok, tokenMasked, tokenLength, hasToken}`（**绝不回完整新 Token**） |
| `/api/net/online` | GET | 任意 | 老的五字段 + `tailscale` + `drift` 摘要 |
| `/api/net/online/mode` | POST | 回环 | `{ok, mode, requestedMode, serverUrl, code?, message?, error?}` |

脱敏实现是 `sanitizeAdmin`（`server/net/LobbyHttp.js`）：删 `idKey.full/key/value`、删 `online.token`、递归把 256 位 hex 打码、丢弃 `serveStatus.raw`。测试断言响应全文不出现 `/[0-9a-f]{256}/`。

非回环来源一律 `403`，文案「只允许本机设置页修改联机配置」；`/api/app/quit` 额外要求 `x-jican-client: launcher` 头（页内脚本拿不到）。

## 3. 配置漂移（drift）

13 个 code，★ 为 fatal：

```
tailscale-not-installed★   tailscale-not-running★     serve-read-failed
online-enabled-but-off★    online-disabled-but-serve   funnel-cap-missing
funnel-cap-allowed-but-off funnel-but-config-tailnet  tailnet-but-config-funnel
port-mismatch              serve-port-mismatch★        leftover-serve-rules
tailnet-port-not-443
```

fatal 用红色、其余黄色；每条带「一键修复」——模式类的直接调 `switchMode`，其它按 `x.action = {url, method, body}` 发请求。

## 4. 踩过的坑（都值得记住）

### 4.1 `h(tag, props, ...children)` 第二个参数是 props，「子元素」会被静默吃掉

`client/js/util/dom.js:9` 的签名是 `h(tag, props = {}, ...children)`。写成

```js
h('div.settings-block', h('div.settings-block-head', {}, '标题'))   // ✗ 整行消失
h('div.settings-block', {}, h('div.settings-block-head', {}, '标题')) // ✓
```

第二实参会被当成 props 然后丢弃，**不报错**。当时 4 个分组的标题行（含「显示完整 / 复制 / 刷新 / 模式切换」）全部不渲染，DOM 里 `.settings-block` 在、`.settings-block-head` 却是 0 个 —— 排查了很久才定位到这一行 `{}`。修复：`SettingsPanel.js` 里 10 处外层 `h` 全部补上显式 `{}`。

### 4.2 `browser_eval` 是隔离世界，测不了真实 DOM 行为

用 `browser_eval` 注入 JS 造元素、读页面行为都不可靠（类名会被丢）。验证 UI 必须用真浏览器：本机没有 playwright 自带浏览器，需要显式 `executablePath: 'C:\\Program Files\\Google\\Chrome\\Application\\chrome.exe'`，`playwright-core` 在 `C:/Users/26339/AppData/Roaming/npm/node_modules/openclaw/node_modules/playwright-core`。另外宿主里 `#btn-settings` `display:none`，`click()` 会 30 秒超时，要改用 `p.evaluate(() => document.getElementById('btn-settings').click())`。

### 4.3 `.overlay` 的 `backdrop-filter` 会让截图看起来「糊成一团」

弹窗背后是 `backdrop-filter: blur(6px)` + 半透明遮罩；截图/远程桌面上容易误判成「内容没渲染」。核对内容是先 `.modal.innerText`，再截图；需要看清排版时临时注入 `.overlay{backdrop-filter:none!important}`。

### 4.4 `OnlineConfig.js` 用了 `dirname` 却没 import

第一次切 Funnel 就 500 `dirname is not defined`。已补 `import { dirname } from 'node:path'`。
