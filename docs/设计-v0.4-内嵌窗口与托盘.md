# 机惨模拟器 v0.4：内嵌应用窗口 + 系统托盘

## 一句话
双击 `jican-simulator-launcher.exe` → 弹出**自带浏览器的应用窗口**（内嵌 WebView2），
同时在**系统托盘**常驻图标；宿主机器上没有任何浏览器也能玩。

## 为什么不是 Electron（像 DeepSeekHarness）
DSH 是 `electron-builder` 打的 Electron 应用：整包自带 Chromium，体积 246 MB + asar 182 MB。
本机已经装了 **Edge WebView2 Runtime**（`%ProgramFiles(x86)%\Microsoft\EdgeWebView\Application\156.0.4314.58`），
Windows 10/11 预装率约 96%，所以用 **WinForms + WebView2** 就能拿到同样的「自带浏览器」效果，
而不用把 90 MB 变成 340 MB。装不上 WebView2 的机器走三层兜底（见下）。

## 三层兜底（保证「没有浏览器也能用」）
1. **WebView2**（本机已装 / Windows 11 预装）→ 内嵌窗口，首选。
2. **WebView2 Evergreen 安装**：从 `https://go.microsoft.com/fwlink/p/?LinkId=2124703` 静默下载安装后重启窗口。
3. **系统默认浏览器** `Process.Start(url)`（老机器兜底；此时退回 v0.3 行为）。

## 进程与窗口结构
```
jican-simulator-launcher.exe  （本文件 = WinForms 宿主，PE Subsystem=2）
  ├─ 释放内嵌 node 运行时到 %LOCALAPPDATA%\JicanSimulator\runtime\rt-<指纹>\
  ├─ CreateProcess(CREATE_NO_WINDOW) → node-runtime.exe launcher.cjs --spawn-only
  │     └─ spawn(jican-simulator.exe --serve)  ← 真正服务端，无窗口、常驻
  ├─ 轮询 %LOCALAPPDATA%\JicanSimulator\server.port 拿到端口
  ├─ 弹出 MainForm（FormBorderStyle=1，内嵌 WebView2 占满客户区）
  └─ NotifyIcon 常驻托盘：左键单击→显示/隐藏窗口；右键菜单→显示主界面 / 浏览器打开 / 看日志 / 退出
```
窗口关闭（X）→ 最小化到托盘，服务继续跑（这才是需求里的「在后台跑了」）。
托盘「退出」→ `POST /api/app/quit` → 服务优雅关停 → 宿主退出。

## Node 侧新增
`server/net/HttpServer.js` 增加两个只接受 POST 的本机端点（已存在 lobbyRouter 放行 POST 的机制）：
- `POST /api/app/ping` → `{ok:true, version, port}`：宿主用来确认「这个端口上是我们的服务」。
- `POST /api/app/quit` → 触发优雅关停；仅当 `req.socket.remoteAddress` 是回环地址且带
  `X-Jican-Client: launcher` 头才接受，防止网页里的第三方脚本关掉服务。
（CSP 的 `connect-src 'self'` 已挡住跨源脚本，这里再加一层。）

## 安全
- 窗口内导航只允许 `http://127.0.0.1:<port>/`；`WebResourceRequested`/`NavigationStarting` 拦截外链改走系统浏览器。
- 关闭 DevTools（非 --debug）。
- 窗口标题 = 机惨模拟器 + 当前联机状态。

## 踩过的坑（都在 2026-11-01 复现并修掉）

### 0. 【最关键】node-runtime.exe launcher.cjs 根本不会执行脚本
`node-runtime.exe` 是 **SEA 单文件**。它的 `process.argv[1]` 只是「业务参数」，**不是脚本路径**——
SEA 启动时永远走内嵌的 `sea-entry.cjs`，所以 `node-runtime.exe launcher.cjs --spawn-only` 的真实效果是
「启动内核，并把字符串 `launcher.cjs` 当成一个无关参数丢掉」。
表现为：`node-runtime.exe` 进程**活着**、服务**也真起着**，但 `launcher.cjs` 里一行代码都没跑
（不写日志、不写锁、不杀旧实例），宿主只能等到 25 秒超时，日志一片空白，极难定位。
**修法**：宿主不再经过 node 运行时，直接 `CreateProcess("jican-simulator.exe", "--serve --data-dir <目录>")`。
内核（`server/index.js` 的 `runCli`）自己就写 `server.port`、挂 `/api/app/quit`，宿主需要的它都有。
`packaging/launcher.cjs` 保留给命令行/开发期使用，注释里已写明这条限制。

### 0b. 宿主 CreateProcess 的 bInheritHandles 必须为 true
`StartChild` 早期传的是 `false`，子进程的 0/1/2 号标准句柄无效，node 一启动就死在 stdio 初始化上
（进程一闪就没）。现在打开 NUL 设备、`DuplicateHandle` 成可继承句柄，再用 `STARTF_USESTDHANDLES`
显式交给子进程。

### 1. 数据目录在宿主链路里传不进去 → 「服务启动超时」但后台其实活着
`packaging/sea-entry.cjs` 曾经无条件执行 `globalThis.__JICAN_DATA_DIR__ = join(exeDir, 'data')`。
`server/persistence/paths.js:33-37` 的优先级是 `globalThis.__JICAN_DATA_DIR__ > process.env.JICAN_DATA_DIR > defaultDataDir()`，
所以宿主经 `launcher.cfg` → `launcher.cjs` → 子进程环境变量传下来的数据目录被无声吃掉，
服务把 `server.port` 写进 `<exe目录>/data`，宿主却去 `%LOCALAPPDATA%\JicanSimulator` 读 → 25 秒超时。
**修法（最终形态）**：`packaging/sea-entry.cjs` 支持 `--data-dir <路径>`，宿主直接把它写进命令行；
优先级变成 `--data-dir > 环境变量 JICAN_DATA_DIR > <exe目录>/data`。
为什么最终不是靠环境变量：宿主的 `CreateProcess` 不能传自定义环境块（本机必 `ERROR_INVALID_PARAMETER(87)`），
环境变量在这条链路上根本到不了子进程；而命令行参数是唯一可靠的通道。
不传 `--data-dir` 时仍退回 `<exe目录>/data`（命令行直接双击的便携版语义不变）。
**定位手段**：临时在入口打 `console.log('[诊断] env JICAN_DATA_DIR=' + process.env.JICAN_DATA_DIR)`，
实测能打印出宿主传的目录，说明变量确实到了进程、问题只在覆盖那一行（诊断行验证后已删除）。

### 2. WebView2 托管程序集没随包分发 → `FileNotFoundException`
`csc /reference:...Core.dll` 只把**程序集引用写进元数据**，运行期仍由 CLR 按「应用基目录 + PATH」去找文件。
以前 `dist/<flavor>/` 里只有两个 exe，宿主一启动就抛：
`System.IO.FileNotFoundException: 未能加载文件或程序集"Microsoft.Web.WebView2.Core, Version=1.0.2903.40, ..."`
**修法**：`build.mjs` 的 `stageWv2()` 把 `Microsoft.Web.WebView2.Core.dll`、`Microsoft.Web.WebView2.WinForms.dll`
和原生 `WebView2Loader.dll`（同时放 `{app}\runtimes\win-x64\native\` 与 `{app}` 两处）拷到产物目录；
两个 Inno 脚本的 `[Files]` 也补了对应条目。

## 验证手段（本机可复现）
截图拿不到 WebView2 内容（GPU 合成桌面下 `CopyFromScreen`/`PrintWindow` 都是空白），所以用**三件套 + 日志**判定：
1. `<数据目录>\server.port` 出现且端口可访问（`Invoke-WebRequest http://127.0.0.1:<port>/ → 200`）。
2. 宿主进程 `MainWindowTitle` = `机惨模拟器 — 机惨模拟器`（说明页面 `<title>` 已回填，即 DOM 真的加载了）。
3. `<数据目录>\logs\host.log` 出现四行：`OnShown 开始` → `InitWebView` → `CoreWebView2 初始化完成，IsSuccess=True` → `导航完成 IsSuccess=True`。
