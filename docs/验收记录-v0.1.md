## 浏览器实测（内置浏览器）

| 操作 | 结果 |
| --- | --- |
| 大厅 | 显示身份/班级/角色选择、规则摘要、AI 增强状态（本机无 Ollama，显示「未启用（纯规则 AI）」）、继续上局入口 |
| 开局与渲染 | 地图、家具、35 名角色、名字与台词气泡；视线外区域为黑色，墙与门正确裁切视野，桌子投下短阴影 |
| 移动 | 键盘移动、被课桌挡住、沿过道走出教室、从门进入办公室；鼠标按住朝指针移动 |
| 提问 | 在赵老师身边按 Q，10 秒后积分「已知变化 +50」，冷却开始 |
| 讨好 | 按 F，「讨好成功，+88 分」 |
| 他人电脑 | 进入白浩然的电脑看到对方积分；主人回来使用时提示「免疫」 |

| 再来一局 / 回大厅 | 均正常 |
| 老师模式 | 金色视野扇形、鼠标控制朝向；电脑旁绿圈（主人自用、免疫）与红圈（他人占用）提示 |
| 读档 | 重启服务后大厅出现「继续上局」，读档后暂停在原帧，继续后正常推进 |
